# Playgrounds

Eine statische GitHub-Pages-Karte für Spielplätze.

- Spielplätze werden für den sichtbaren Kartenausschnitt über Overpass/OpenStreetMap geladen.
- Der ausgewählte Spielplatz kann als besucht markiert werden; Datum und Uhrzeit werden gespeichert.
- Bewertungen von 0 bis 10 werden je Kategorie in `localStorage` des Browsers gespeichert.
- „In Google Maps öffnen“ öffnet die Google-Maps-Suche für den ausgewählten Spielplatz.

Die Seite benötigt keine API-Schlüssel und kann direkt über GitHub Pages gehostet werden.
