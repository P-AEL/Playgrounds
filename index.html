Better outside, together.

Visits and ratings are stored centrally. Each playground has one shared rating. Anyone with access to this site can update it, without signing in.

  1. Create a project on the Supabase Free plan.
  2. Run supabase/schema.sql in the SQL editor.
  3. In GitHub, set the repository variables SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY, then publish the site.

See the README for step-by-step instructions. You can explore places now; saving is disabled until storage is connected. Free projects may pause after inactivity and need to be resumed in the Supabase dashboard.

Shared storage is connected. Changes are loaded when you open the site, return to this tab or select Refresh shared data.
PLAYGROUND ATLAS

There is more to your city.

Discover playgrounds and outdoor gyms from OpenStreetMap, log visits with a date and time, and rate Variety, Climbability and Pull ups possibility from 0 to 10.

The map loads recorded places in the selected area. Move the map and select Search this area. Data quality and access on site cannot be guaranteed.

Records are shared through Supabase and are visible to visitors of this site. There are no individual profiles. Export saves the most recently loaded snapshot of the shared collection.

Map areas are sent to OpenStreetMap and Overpass, submitted place names to Nominatim, and saved records to the configured Supabase project. Your location is used only when you select Near me; the subsequent search sends the map area to the map services.
